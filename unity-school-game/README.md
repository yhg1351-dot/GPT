# 우리의 첫 번째 선택

6학년 도덕 함께 읽기 후 진행하는 학생 개인별 선택형 이야기 게임입니다.

[학생용 게임 열기](https://rawcdn.githack.com/yhg1351-dot/GPT/1ae20b12846fad39f346dc0435821901ded59b46/unity-school-game/index.html)

- 약 12~15분, 세 장면의 선택과 결과, 마지막 편지와 다음 읽기 질문으로 구성합니다.
- PPT 도입부 1~37쪽 부근까지 함께 읽은 뒤 사용합니다. 전체를 이미 읽었다면 시작 안내에서 해당 항목을 선택합니다.
- 게임의 장면·대사·결과는 원자료를 바탕으로 만든 수업용 창작입니다.
- 로그인과 설치가 필요 없으며 선택과 메모는 각 브라우저에만 저장됩니다. 교사에게 자동 전송되지 않습니다.
- 처음 웹 주소에 들어갈 때 호스팅 서비스의 확인 화면이 표시될 수 있습니다.
- 공용 기기에서는 기록 저장 후 새로 시작을 눌러 초기화합니다.

## 파일 및 검증

index.html 하나에 스타일과 스크립트가 모두 포함되어 있습니다. 외부 이미지·폰트·API 의존성은 없습니다.

27개 선택 경로, 기록 저장 데이터, 이어 하기와 초기화 동작을 코드로 점검했습니다. 공개 GitHub 파일을 다시 읽어 확인했습니다. 게시 시점의 실행 환경에서는 브라우저 도구 연결 문제로 실제 화면 실행 검증을 완료하지 못했습니다.
